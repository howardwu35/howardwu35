# 💫 About Me:
I’m a cybersecurity student at Penn State with a focus on application development and security engineering. I have hands-on experience in vulnerability management, incident response, and risk quantification, including building frameworks using ALE/ARO/SLE models to support real-world security decisions.<br><br>I’ve worked with tools like Microsoft Sentinel, Splunk, and Nessus, and have built projects ranging from SIEM-based honeypots to full-stack security dashboards using React and FastAPI. I’m especially interested in threat detection, cloud security, and translating complex security data into actionable insights.<br><br>Currently, I’m working toward my CCNA and actively building projects that combine security, data, and real-world impact.
