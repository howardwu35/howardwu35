# sample-output/ (SYNTHETIC DATA)

> ⚠️ These files were generated by `scripts/nessus_report.py` from the **synthetic test fixtures** in
> `tests/fixtures/`. They are **not** real scan results. They show the format of each deliverable.
> Real lab results are in `reports/`.

Regenerate:
```bash
python3 tests/make_fixtures.py
python3 scripts/nessus_report.py report tests/fixtures/synthetic_baseline.nessus -o sample-output \
  --assets assets.example.csv --kev tests/fixtures/synthetic_kev.csv \
  --title "SAMPLE Vulnerability Assessment Report (Synthetic Data)"
python3 scripts/nessus_report.py diff tests/fixtures/synthetic_baseline.nessus \
  tests/fixtures/synthetic_rescan.nessus -o sample-output \
  --assets assets.example.csv --kev tests/fixtures/synthetic_kev.csv
```
